# Changelog

## 0.6.1

Initial Marketplace release.

- Added live before/after stack columns and an accessible stack inspector.
- Added profile-driven diagnostics, hover information, completions, and formatting.
- Added bundled Forth 2012, ANS94, Gforth, SwiftForth, and VFX Forth profiles.
- Added workspace-defined profiles through `.forth-evaluator.json`.
- Added per-workspace stack display controls and per-profile completion frequencies.
